# 온가족 한상 과제 피드백 정리

| No | 화면/영역 | 피드백 내용 | 유형 | 개선 방향 |
|:-:|---|---|:-:|---|
| 1 | 가족 구성 (캐릭터) | 청소년 여자 캐릭터 이미지가 아줌마처럼 보임 *(2회 언급)* | 디자인 | 청소년답게 캐릭터 리디자인 |
| 2 | 가족 구성 (연령) | 연령을 숫자로 표기하는 게 좋겠음 | UX | "청소년" 대신 "13~18세"처럼 숫자 범위로 표시 |
| 3 | 가족 구성 (연령) | 청소년까지는 잘 나뉘지만 성인·노인은 기준이 애매하고 너무 포괄적임 | UX | 성인·노인 구간을 세분화하고 기준 연령 명시 |
| 4 | 공유하기 이후 | 가족 만족도나 다른 집 레시피를 본 뒤 뒤로가기를 하면 공유하기 페이지가 다시 떠서 불편함 | UX/버그 | 공유 완료 후 페이지 이동 방식 수정 (뒤로가기 흐름 정리) |
| 5 | 식사 후 기록 | 식사 후 남기는 예시 표현이 너무 단순함 | 콘텐츠 | 맛·양·가족 반응 등 다양한 예시 문구 제공 |
| 6 | 재료 입력 | 재료를 한꺼번에 입력했는데 하나씩 넣어야 하는 방식이었음 | UX | "하나씩 입력하고 추가를 누르세요" 안내 문구 표시 (또는 쉼표로 여러 개 입력 지원) |
| 7 | 냉장고 사진 인식 | 냉장고 사진을 찍으면 재료를 제대로 인식하지 못함 | 기능/정확도 | 인식 정확도 개선 + 인식 결과를 사용자가 수정할 수 있게 |
| 8 | 레시피 생성 | 레시피가 나오는 속도가 조금 더 빨랐으면 함 | 성능 | 응답 속도 개선 (생성 중 내용을 순차적으로 보여주기 등) |
| 9 | 레시피 상세 | 요리 팁(재료별 손질법 등)이 있으면 좋겠음 | 신규 기능 | 재료별 손질법·조리 팁 섹션 추가 |
| 10 | 레시피 상세 | 영양성분 표기가 나오면 더 좋겠음 | 신규 기능 | 칼로리·탄단지 등 영양성분 정보 추가 |
