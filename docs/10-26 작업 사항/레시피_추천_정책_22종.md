```
[공통 규칙]

- 판정 상태: PASS(확인된 정보에서 회피 대상이 없고 필수 미확인 정보가 없음. 안전 보증이 아님) / BLOCKED(회피 대상이 확인됨, 추천 제외) / NEEDS_REVIEW(정보 부족·모호, 추천 보류) / SYSTEM_ERROR(조회·엔진 오류).

- 대체 재료를 제안하면 그 재료를 처음부터 다시 검증한다.
- 라벨에 주의 문구가 없다는 이유로 교차오염이 없다고 추정하지 않는다.
- 저장된 레시피는 가족 프로필이 바뀌면 안전 검사를 다시 완료한 뒤 표시한다.

- 굴소스, 해물 육수, 해물 믹스, 오징어 먹물, 젓갈, 시판 양념은 제품별 원재료표와 하위 원재료를 확인한다. 확인할 수 없으면 NEEDS_REVIEW로 둔다.
- 등록된 항목이 확인되면 BLOCKED. 같은 기름·팬·도마의 교차오염 주의를 안내한다.
- 대체 재료를 제안하면 처음부터 다시 검증한다.
- 1차 공통 조리 후 해당 재료를 추가하는 것은 알레르기가 없는 구성원 몫에만 허용한다.
```

## B. 당뇨식 (4종)

### DM-01 탄수화물·당류 검사와 끼니 배분

```
[DM-01] 당뇨식: 탄수화물·당류 검사와 끼니 배분
- 대상: 프로필의 건강상 식사 조건에서 '당뇨식'을 선택한 구성원.
- 식약처 식품영양성분DB의 100g당 탄수화물·당류·식이섬유를 사용하며, 재료 사전의 검색명과 이름이 정확히 일치하는 항목만 쓴다. 모호하거나 데이터가 없으면 NEEDS_REVIEW로 둔다.
- 탄수화물·당류의 판정 기준값은 전문가 확정 전이다. 기준값이 확정되지 않았으므로 수치로 통과를 판정하지 않고 NEEDS_REVIEW로 둔다. AI는 임의의 수치 기준을 만들지 않는다.
- 끼니 구성은 당뇨병 식품교환표(2023 제4판)의 식품군과 끼니 배분 방식을 참고한다. 탄수화물을 한 끼에 몰지 않도록 곡류·과일·우유의 양을 나누어 제안한다.
- 극단적인 탄수화물 제한 식단은 제안하지 않는다. 영양 불량 위험이 있는 구성원(고령·임신·수유 등)에게 탄수화물을 줄이는 식단을 제안하지 않는다.
- 의사·영양사가 개별 지침을 준 경우 그 지침이 우선한다.
```

### DM-02 식이섬유·곡물의 질

```
[DM-02] 당뇨식: 식이섬유와 곡물의 질
- 대상: '당뇨식' 구성원.
- 재료군 근거 태그는 설명과 대체 제안에만 쓰며 판정을 통과로 바꾸지 못한다.
- 유리한 재료군: 콩류, 통곡물, 식이섬유가 풍부한 채소. 불리한 재료군: 정제곡물, 첨가당, 붉은 고기, 가공육. 태그는 사람이 확정한 것만 사용하며 사용자 요청 중에 논문을 조회하거나 초록을 자동 해석하지 않는다.
- 근거 방향: 최근 메타분석(Obes Rev 2025, PMID 39295498)은 당뇨 관리에서 탄수화물 총량보다 식이섬유 섭취가 더 중요하다고 보았고, 점성 수용성 식이섬유가 혈당·지질 조절에 유익하다는 분석(Front Nutr 2023)도 있다. 탄수화물 감소가 혈당을 개선한다는 분석도 있어 학계 의견이 갈리므로 단정하는 설명을 쓰지 않는다.
- 쌀밥을 잡곡밥으로, 주스를 생과일로 바꾸는 식의 대체를 제안하되 대체 재료를 다시 검증한다.
- 두부·대두는 근거를 아직 수집하지 않았으므로 유리하다고 설명하지 않는다. 식이섬유 섭취 목표 수치는 원문 확인 전까지 제시하지 않는다.
```

### DM-03 당류·첨가당·가당음료

```
[DM-03] 당뇨식: 당류·첨가당·가당음료
- 대상: '당뇨식' 구성원.
- 방향: 2025 한국인 영양소 섭취기준(보건복지부)은 총당류를 총에너지의 20% 이내, 첨가당을 10% 이내로 제한하고 가당음료는 가능한 줄이도록 한다(복수 보도 기준이며 복지부 원문 확인 전).
- 설탕, 시럽, 꿀, 조청, 올리고당 같은 첨가당은 레시피에서 최소로 쓰고, 단맛이 필요하면 과일·채소 등 재료 자체의 단맛을 먼저 제안한다.
- 주스, 탄산, 가당 커피, 가당 요거트를 곁들임으로 제안하지 않는다. 음료가 필요하면 물이나 무가당 차를 제안한다.
- 소스, 양념, 시판 가공식품의 당류는 성분표 확인이 필요하다고 안내하고, 데이터가 없으면 NEEDS_REVIEW로 둔다.
- 첨가당의 에너지 비율을 계산하려면 총열량과 분량이 필요하므로, 분량이 없으면 수치 판정 없이 NEEDS_REVIEW로 둔다.
- 감미료 대체는 근거를 확인하기 전에는 제안하지 않는다.
```

### DM-04 판정 우선순위·보류·견과류 조건부

```
[DM-04] 당뇨식: 판정 우선순위와 보류 규칙
- 대상: '당뇨식' 구성원.
- 판정은 공통 규칙의 우선순위(SYSTEM_ERROR > BLOCKED > NEEDS_REVIEW > PASS)를 따른다. 기준값이 확정되지 않았거나 데이터가 없으면 통과 대신 NEEDS_REVIEW로 둔다. 재료 이름이 모호하거나 분량이 없어도 같다.
- 근거 태그(유리·불리)는 설명과 대체 제안용이며 판정을 통과로 바꾸지 못한다.
- 견과류는 혈당 면에서 조건부로 유리하지만, 견과류 알레르기 구성원이 있으면 알레르기 규칙이 항상 우선한다.
- 당뇨식 구성원의 조건을 다른 구성원에게 자동 적용하지 않는다. 공동 요리는 한 번 조리한 뒤 구성원별로 양념·곁들임·분량을 변형하고 변형 이유를 함께 표시한다.
- 의사·영양사의 개별 지침이 있으면 그것이 우선한다. 이 정책은 의료적 진단이나 치료 지침이 아니다.
- 가족 프로필이 바뀌면 저장된 레시피의 안전 검사를 다시 완료한 뒤 표시한다.
- 화면에는 고지문을 함께 표시한다.
```

### NA-01 재료별 나트륨 검사

```
[NA-01] 저염식: 재료별 나트륨 검사
- 대상: 프로필의 건강상 식사 조건에서 '저염식'을 선택한 구성원.

- 소금 1g은 나트륨 약 400mg으로 환산해 설명한다.
- 저염 대체 제품을 제안해도 그 제품의 나트륨을 다시 검사한다. 제품명만으로 수치를 추정하지 않는다.
```

### NA-02 1인분 합산 한도

```
[NA-02] 저염식: 1인분 합산 한도
- 대상: '저염식' 구성원.
- 하루 기준은 나트륨 2,300mg이다(2020 한국인 영양소 섭취기준의 만성질환위험감소섭취량. 2025 개정 수치는 원문 확인 전이며 확정 전까지 이 값을 유지한다).

- 의사·영양사가 개별 한도를 정한 경우 그 한도가 우선한다.
- 하루 한도는 한 끼가 아니라 하루 전체로 안내하며, 한 끼 770mg은 계산상의 참고 배분이다.
```

### NA-03 시판 양념·국물 분량

```
[NA-03] 저염식: 시판 양념·국물과 분량 기준
- 대상: '저염식' 구성원.
- 식품교환표에 없는 시판 양념·소스·가공식품의 분량은 식약처 1회 섭취참고량을 기준으로 규칙 엔진이 채운다. AI가 분량을 정하지 않는다.
- 국, 찌개, 면 국물, 절임류는 나트륨 주 공급원이므로 건더기 위주로 담고 국물은 적게 먹도록 제안한다.
- 시판 제품은 영양성분표의 나트륨 함량을 확인하도록 안내한다. 영양성분 표시가 없거나 제품명만 있으면 NEEDS_REVIEW로 둔다.
- 영양강조 표시 중 '무'(100g당 5mg 미만)는 참고할 수 있다. '저나트륨' 표시의 정확한 기준은 공식 원문 확인 전이므로 판정에 쓰지 않는다.
- '무가염'·'나트륨 무첨가' 표시는 제품 자체에 들어 있는 나트륨까지 없다는 뜻이 아닐 수 있으므로 통과의 근거로 쓰지 않는다.
- 외식·배달 음식은 정확한 수치를 알 수 없으면 NEEDS_REVIEW로 둔다.
```

### NA-04 마지막 단계 양념 조절과 안전

```
[NA-04] 저염식: 양념 조절·완성 레시피 비교·안전
- 대상: '저염식' 구성원.
- 공통 요리는 한 번에 조리하고, 저염식 구성원은 마지막 단계에서 양념과 곁들임으로 조절한다. 간을 하기 전에 저염식 구성원 몫을 덜어내고 따로 간을 맞추는 방식을 제안하며 변형 이유를 표시한다.
- 짠맛을 대신하는 맛은 마늘·생강·양파·후추·고추 같은 향신 재료로 낸다.
- 완성된 레시피의 나트륨은 식약처 조리식품 레시피 DB의 비슷한 메뉴 범위와 비교하고, 크게 벗어나면 NEEDS_REVIEW로 두거나 다시 생성한다(비교 범위 규칙은 미확정).
- 칼륨이 든 대체염과 칼륨 보충 권유는 제안하지 않는다. 칼륨을 제한해야 하는 구성원(예: 신장질환)이 있을 수 있고 국내 지침에도 아직 포함되지 않았다.
- 지나치게 낮은 나트륨 식단은 제안하지 않는다. 의사·영양사가 정한 목표가 있으면 그것이 우선한다.
- 가족 프로필이 바뀌면 저장된 레시피를 다시 검사한다.
```

## D. 정량 (1종)

### QT-01 4인분 정량 기준

```
[QT-01] 정량: 4인분 기준
- 모든 레시피는 4인분(성인 1인분 × 4) 기준으로만 제공한다. 총량은 4인분으로 고정하고, 어린이·노인 등 구성원별 배분은 변형 단계에서 조절한다.
- AI는 재료와 조리법만 제안한다. 분량은 규칙 엔진이 재료 사전의 기준량(식품교환표 1교환단위량, 식약처 1회 섭취참고량, 식품영양성분DB의 가식부 비율·개당 중량)으로 채운다.
- 표시: g·mL 기본, 개수는 g을 함께 쓴다. 1컵 200mL, 1큰술 15mL, 1작은술 5mL로 계량한다. 손질 후 먹는 부분(가식부) 기준으로 표시하고 구입량은 폐기율로 환산한다.
- 반올림(팀 결정안): g은 5단위, mL는 10단위, 개수·큰술은 0.5단위.
- 완성된 4인분 레시피의 총 중량·열량·나트륨은 식약처 조리식품 레시피 DB의 비슷한 메뉴 범위와 비교하고, 크게 벗어나면 NEEDS_REVIEW로 두거나 다시 생성한다.
- 어린이·노인 분량 환산계수는 확정 전이므로 AI가 임의로 환산하지 않는다. 분량이 없으면 안전 검사는 NEEDS_REVIEW로 둔다.
- 식재료 등록 단계에서는 수량을 저장하지 않는다.
```

## E. 유동식 (3종, 경관식 제외)

### LQ-01 맑은 유동식

```
[LQ-01] 맑은 유동식(Clear Liquid)
- 대상: 의료진 지시 등으로 맑은 유동식이 필요하다고 사용자가 지정한 구성원. 경관식(튜브 급식)은 이 서비스의 대상이 아니다.
- 이 정의는 일반 참고용이며 국내 병원 공식 기준은 확인 전이다. 병원·의료진의 지시가 항상 우선한다.
- 정의: 고형물과 과육이 없고 용기 너머가 비쳐 보이는 액체.
- 허용 예: 건더기 없는 맑은 국물(채소·닭고기·쇠고기), 젤라틴, 과육 없는 맑은 주스, 우유·크림을 넣지 않은 차·커피, 맑은 스포츠음료, 물.
- 제외: 고형식, 우유·유제품, 뼈 국물, 과육·펄프가 있는 음료, 술. 검사 준비용이면 붉은색·보라색 음식도 제외한다.
- 열량과 단백질이 부족하므로 의료진이 정한 기간을 넘기지 않도록 안내한다. 당뇨 구성원은 열량이 필요할 수 있어 무설탕만 고집하지 않고 의료진 지시를 따른다.
- 젤라틴·육수 제품은 알레르기 정책(돼지고기·쇠고기·닭고기 등)을 다시 적용한다. 나트륨은 저염 정책 한도에 합산한다.
```

### LQ-02 일반(완전) 유동식

[LQ-02] 일반 유동식(Full Liquid)
- 대상: 의료진이 일반 유동식을 지정했다고 사용자가 입력한 구성원. 경관식은 대상이 아니다.

- 정의나 지시 정보가 없으면 NEEDS_REVIEW로 둔다.

### LQ-03 연하곤란식

```
[LQ-03] 연하곤란식(물성 조절식)
- 대상: 삼킴 곤란이 있어 의료진·언어치료사가 단계를 지정했다고 사용자가 입력한 구성원. 경관식은 대상이 아니다.
- 단계는 사용자가 입력한 값을 그대로 쓴다. AI가 단계를 정하거나 바꾸지 않으며, 입력이 없으면 NEEDS_REVIEW로 둔다.
- 단계 체계: 국내 고령친화식품 KS H 4897은 1단계 치아, 2단계 잇몸, 3단계 혀로 섭취하는 3단계이고, 국제 IDDSI는 0~7의 8단계다. 사용자가 입력한 체계를 그대로 표기하고 두 체계를 자동으로 서로 환산하지 않는다.
- 경도·점도 수치와 시험 방법은 단위 확인 전이므로 쓰지 않는다. 대신 단계에 맞는 조리 방식(곱게 갈기, 체에 거르기, 부드럽게 익히기)만 안내하고 최종 물성은 직접 확인하도록 안내한다.
- 점도를 임의로 높이지 않는다. 지나친 증점은 수분 섭취를 줄일 수 있다.
- 증점제 제품은 알레르기·나트륨을 제품별로 확인한다. 국물과 건더기가 섞인 음식은 물성이 달라질 수 있어 NEEDS_REVIEW로 둔다.
- 물성만 맞추면 영양이 충분해지는 것은 아니므로 열량·단백질 부족 가능성을 안내한다.
```
