Final Project 주제 제안
프로젝트 주제
AI 개인 스타일 코디 매니저
내 옷장과 취향을 기억하고, 날씨와 상황에 맞는 개인 맞춤형 코디를 추천해주는 AI 스타일 매니저

---

아이디어
매일 옷을 입을 때

"오늘 뭐 입지?"

라는 고민을 해결해주는 AI 패션 코디 서비스이다.

사용자가 자신의 옷을 사진으로 등록하면 AI가 옷의 종류, 색상, 스타일 등을 분석하여 개인 옷장을 구성한다.

이후 사용자가

"내일 출근할 때 뭐 입지?"

"주말에 친구를 만나는데 편하게 입고 싶어."

와 같이 요청하면 사용자의 실제 옷장 + 개인 취향 + 날씨 + 일정/상황을 종합하여 맞춤형 코디를 추천한다.

---

해결하려는 문제
옷은 많은데 서로 어떻게 조합해야 할지 모르겠다.
매일 코디를 결정하는 데 시간이 많이 걸린다.
날씨와 상황까지 고려해서 옷을 고르기 어렵다.
인터넷의 일반적인 패션 추천은 내 취향이나 내가 가진 옷을 충분히 반영하지 못한다.

→ 해결 방법
"내가 가지고 있는 옷을 중심으로 나에게 맞는 코디를 AI가 추천해준다."

---

주요 기능
① AI 옷장
옷 사진을 업로드하면 AI가 옷의 정보를 분석하고 내 옷장에 등록한다.

상의
하의
아우터
원피스
신발
가방 등

② AI 코디 추천
사용자가 날짜, 상황 또는 원하는 스타일을 입력하면 AI가 코디를 추천한다.

예:

"내일 출근할 때 입을 옷 추천해줘."

③ 날씨 기반 추천
날씨 정보를 확인하여 기온, 비, 바람 등을 고려한 코디를 추천한다.

④ 개인 취향 기억
사용자가 좋아하거나 싫어하는 코디를 기억하여 사용할수록 개인화된 추천을 제공한다.

예:

좋아하는 색상
선호하는 스타일
선호하는 핏
자주 선택하는 옷
싫어하는 스타일

⑤ AI Agent
사용자의 요청에 따라 AI가 필요한 정보를 확인하고 코디를 구성한다.

사용자 요청 → 취향 확인 → 옷장 확인 → 날씨 확인 → 상황 분석 → 코디 추천

---

핵심 AI 기술
과제의 필수 기술 요소 중 다음 기술을 활용한다.

멀티모달 AI
옷 사진을 AI가 분석하여 옷의 종류, 색상, 스타일 등을 파악한다.

Long-term Memory
사용자의 취향과 과거 피드백을 저장하여 다음 코디 추천에 활용한다.

AI Agent
사용자의 요청에 따라 옷장, 사용자 취향, 날씨 등의 정보를 활용하여 최종 코디를 결정한다.

추가 검토
개발 일정에 여유가 있을 경우 RAG를 활용하여 최신 패션 트렌드나 스타일 정보를 코디 추천에 반영하는 기능을 추가한다.

# Final Project 기획서

## 1. 프로젝트 개요

### 1.1 프로젝트명

**AI 개인 스타일 코디 매니저**

### 1.2 한 줄 소개

**내 옷장과 취향을 기억하고, 날씨와 상황에 맞는 개인 맞춤형 코디를 추천해주는 AI 스타일 매니저**

### 1.3 프로젝트 목적

매일 옷을 입을 때 많은 사람들이 "오늘은 무엇을 입지?"라는 고민을 한다.

옷은 충분히 가지고 있지만 서로 어떤 옷을 조합해야 할지 모르거나, 날씨와 일정에 맞는 옷을 선택하는 데 시간이 많이 걸리는 문제가 있다.

기존의 패션 추천 서비스는 사용자의 실제 옷장보다는 판매 상품이나 일반적인 스타일을 추천하는 경우가 많아 사용자가 가지고 있는 옷을 활용한 개인화된 코디 추천에는 한계가 있다.

본 프로젝트에서는 생성형 AI와 AI Agent를 활용하여 사용자의 옷을 이미지로 등록하고, 사용자의 스타일 선호도를 기억하며, 날씨와 일정 및 상황을 종합하여 **사용자가 실제로 가지고 있는 옷을 중심으로 코디를 추천하는 AI 서비스**를 개발한다.

---

# 2. 문제 정의

## 2.1 사용자가 겪는 문제

### 문제 1. 매일 코디를 결정하는 데 시간이 걸린다.

출근, 등교, 모임, 데이트, 여행 등 상황에 따라 적절한 옷을 선택해야 하지만 매일 새로운 코디를 생각하는 것은 번거롭다.

### 문제 2. 옷은 많지만 조합하기 어렵다.

사용자가 가지고 있는 옷을 한눈에 파악하기 어렵고, 각각의 옷을 어떤 아이템과 조합해야 할지 판단하기 어렵다.

### 문제 3. 날씨와 상황까지 고려하기 어렵다.

기온, 비, 바람 등의 날씨와 출근, 데이트, 모임 등의 상황을 동시에 고려하여 코디를 선택하는 데 시간이 필요하다.

### 문제 4. 일반적인 패션 추천은 개인 취향을 충분히 반영하지 못한다.

인터넷에서 제공하는 코디 정보는 일반적인 추천인 경우가 많으며, 사용자가 선호하는 색상이나 핏, 스타일과 실제 보유한 옷을 충분히 고려하지 못한다.

# 3. 해결 방법

본 서비스는 사용자의 옷장과 취향을 AI가 이해하고 기억하도록 한다.

사용자가 옷 사진을 등록하면 AI가 이미지를 분석하여 옷의 종류, 색상, 스타일 등의 정보를 추출한다.

사용자가 선호하는 스타일과 코디에 대한 피드백을 지속적으로 저장하고, 사용자가 코디를 요청할 때 이를 활용한다.

또한 날씨와 사용 목적을 함께 분석하여 현재 상황에 적합한 코디를 추천한다.

### 기본 서비스 흐름

사용자

↓

옷 사진 등록

↓

AI 이미지 분석

↓

내 옷장 데이터 생성

↓

사용자 스타일 및 선호도 저장

↓

날씨 및 상황 입력

↓

AI Agent가 정보 분석

↓

개인 맞춤 코디 생성

↓

사용자 피드백 저장

↓

다음 코디 추천에 반영

---

# 4. 타겟 사용자

## 4.1 주요 타겟

**패션에 관심은 있지만 매일 코디를 결정하는 데 시간과 고민이 필요한 30~40대 여성**

### 주요 특징

- 출근 및 일상생활에서 다양한 상황에 맞는 옷을 입어야 한다.
- 옷을 여러 벌 가지고 있지만 매번 새로운 조합을 생각하기 어렵다.
- 지나치게 유행을 따르기보다 자신의 스타일에 맞는 코디를 선호한다.
- 실제로 가지고 있는 옷을 활용한 추천을 원한다.
- AI 서비스를 이용해 생활 속 반복적인 고민을 줄이고 싶어 한다.

## 4.2 사용자 확대

초기에는 30~40대 여성을 중심으로 서비스를 개발하지만 향후에는 남성 및 다른 연령대로 서비스를 확장할 수 있다.

# 5. 핵심 기능

## 5.1 AI 옷장 등록

사용자가 자신의 옷 사진을 업로드하면 AI가 이미지를 분석한다.

### AI가 분석하는 정보

- 의류 종류
- 색상
- 패턴
- 소재
- 스타일
- 계절
- 활용 가능한 상황

예:

> 사진 업로드 → "베이지 니트 / 여성 상의 / 캐주얼 / 봄·가을 / 출근·일상"

분석 결과를 사용자의 옷장에 저장한다.

---

## 5.2 내 옷장 관리

사용자가 등록한 옷을 카테고리별로 확인할 수 있다.

### 카테고리

- 상의
- 하의
- 아우터
- 원피스
- 신발
- 가방
- 액세서리

사용자는 등록된 정보를 수정하거나 삭제할 수 있다.

---

## 5.3 AI 코디 추천

사용자가 상황을 입력하면 AI가 등록된 옷을 활용하여 코디를 추천한다.

### 입력 예시

> "내일 출근할 때 입을 옷 추천해줘."

또는

> "주말에 친구를 만나는데 편하면서 예뻐 보이는 코디 추천해줘."

AI는 사용자의 옷장과 스타일 정보를 바탕으로 코디를 구성한다.

### 추천 결과

- 상의
- 하의
- 아우터
- 신발
- 가방
- 액세서리
- 코디 설명

---

# 6. 날씨 기반 코디 추천

사용자가 날짜와 장소를 선택하면 날씨 정보를 확인하여 코디에 반영한다.

예를 들어:

> 기온 8℃ / 비 / 강한 바람

이라면 AI가 얇은 옷보다는 보온성과 방수성을 고려한 코디를 추천한다.

반대로

> 기온 28℃ / 맑음

이라면 통풍이 좋은 옷을 중심으로 추천한다.

### 활용 데이터

- 기온
- 강수 여부
- 강수 확률
- 바람
- 체감온도

---

# 7. 사용자 취향 Memory

서비스를 사용할수록 사용자의 스타일 선호도를 저장한다.

### 저장 가능한 정보

- 선호 스타일
- 선호 색상
- 선호 핏
- 선호하지 않는 스타일
- 선호하는 옷
- 자주 선택하는 코디
- 사용자가 좋아요를 누른 코디
- 사용자가 싫어요를 누른 코디

예:

> "사용자는 베이지, 블랙 계열의 차분한 색상을 선호하고 여유 있는 핏을 선호함."

이러한 정보를 다음 코디 추천에 활용한다.

---

# 8. AI Agent

단순히 사용자의 질문에 답하는 챗봇이 아니라, 여러 정보를 확인하고 코디를 결정하는 **AI Agent**를 구현한다.

### Agent Workflow

사용자 요청

↓

사용자 취향 Memory 확인

↓

사용자 옷장 확인

↓

날씨 정보 확인

↓

상황 분석

↓

조건에 맞는 옷 선별

↓

코디 조합 생성

↓

추천 이유 설명

### 예시

사용자:

> "이번 토요일에 친구들과 카페에 갈 건데 뭐 입지?"

Agent:

1. 토요일 날씨 확인
2. 사용자의 선호 스타일 확인
3. 사용자의 옷장 검색
4. 카페 모임에 적합한 옷 선별
5. 코디 조합 생성
6. 최종 코디 추천

---

# 9. 필수 기술 요소

본 프로젝트에서는 과제에서 요구하는 기술 요소 중 다음 기술을 핵심적으로 활용한다.

## 9.1 멀티모달 AI

**이미지 + 텍스트를 함께 처리**

사용자가 업로드한 옷 사진을 AI가 분석하여 의류 정보를 추출한다.

활용 예:

- 옷 종류 분석
- 색상 분석
- 스타일 분석
- 계절 및 활용도 분석

---

## 9.2 Long-term Memory

사용자의 스타일 선호도와 서비스 이용 기록을 장기적으로 저장한다.

이를 통해 사용자가 서비스를 반복적으로 사용할수록 개인화된 추천이 가능하도록 한다.

---

## 9.3 AI Agent

사용자의 요청을 분석하고 필요한 정보와 도구를 활용하여 최종 코디를 생성한다.

예:

**사용자 요청 → 날씨 확인 → Memory 조회 → 옷장 검색 → 코디 생성**

---

# 10. 선택적 기술 요소

개발 일정에 여유가 있을 경우 다음 기능을 추가한다.

## 10.1 RAG

패션 트렌드 및 스타일 관련 자료를 검색하여 코디 추천에 활용한다.

예:

> "2026년 가을 트렌드를 반영한 출근 코디를 추천해줘."

RAG가 최신 패션 관련 자료를 검색하고 AI가 해당 정보를 코디 추천에 활용한다.

### RAG 활용 데이터

- 시즌별 패션 트렌드
- 컬러 트렌드
- 스타일 정보
- 상황별 코디 자료
- 체형별 코디 자료

---

# 11. 사용자 피드백

과제 요구사항에 따라 **최소 5명 이상의 실제 사용자**를 대상으로 서비스를 테스트한다.

## 11.1 테스트 방법

사용자에게 실제 자신의 옷을 등록하게 하고 AI 코디 추천을 사용하도록 한다.

### 테스트 과제

1. 옷 5개 이상 등록
2. 자신의 스타일 정보 입력
3. 출근 코디 요청
4. 외출 코디 요청

### 피드백

> "내가 좋아하지 않는 색상이 계속 추천된다."

### 개선

사용자의 좋아요/싫어요 데이터를 Memory에 저장하고 다음 추천에서 반영한다.

이를 통해

**1차 개발 → 사용자 테스트 → 문제 발견 → 개선 → 2차 테스트**

# 2. 문제 정의

## 핵심 Pain Point

1. 냉장고에 어떤 식재료가 남아 있는지 기억하기 어렵다.
2. 가지고 있는 식재료를 조합해서 무엇을 만들 수 있는지 생각하기 어렵다.
3. 매일 식사 메뉴를 결정하는 데 시간과 고민이 필요하다.
4. 개인이나 가족의 음식 취향과 조리 시간까지 고려하여 메뉴를 결정하기 어렵다.
5. 사용하지 못한 식재료가 남아 음식물 낭비로 이어질 수 있다.

## 문제의 근거

**현재는 기획 단계이므로 구체적인 통계나 사용자 조사 결과를 임의로 작성하지 않는다.**

개발 초기 단계에서 실제 사용자 5명 이상을 대상으로 인터뷰 또는 설문을 진행하여 다음 내용을 조사한다.

- 메뉴를 결정할 때 가장 어려운 점
- 냉장고 속 재료를 얼마나 자주 확인하는지
- 남은 재료를 활용하는 데 어려움이 있는지
- 레시피 검색 서비스를 사용할 때 불편한 점
- AI 냉장고 기반 요리 추천 서비스에 대한 요구사항

## 기존 솔루션의 한계

기존 레시피 검색 방식은 사용자가 직접 재료나 음식명을 검색하고 적절한 레시피를 선택해야 한다.

또한 일반적인 레시피 추천만으로는 다음 정보를 동시에 반영하기 어렵다.

- 현재 보유한 식재료
- 사용자의 음식 취향
- 가족 구성원의 취향
- 원하는 조리 시간
- 요리 난이도
- 남은 식재료 활용

## 차별점

**레시피를 검색해주는 서비스가 아니라, 사용자의 냉장고를 이해하고 현재 가지고 있는 재료를 중심으로 요리를 결정해주는 AI 서비스**를 목표로 한다.

핵심은 **냉장고 이미지 분석 + 사용자 취향 Memory + AI Agent**의 결합이다.

# 3. AI 설계

## 사용할 AI/모델

- Google Gemini API
- 멀티모달 이미지 분석
- 생성형 AI
- AI Agent Workflow

추후 필요에 따라 Embedding, Vector Database, RAG를 추가한다.

## AI 핵심 기능

### ① 냉장고 이미지 분석
냉장고 사진을 입력하면 AI가 식재료를 분석한다.

예: 냉장고 사진 → 계란, 두부, 대파, 양파, 김치 등 식재료 추출

### ② 요리 추천
냉장고 재료와 사용자의 요청 조건을 분석하여 만들 수 있는 요리를 추천한다.

### ③ 개인화 추천
사용자의 음식 취향과 과거 피드백을 Memory로 저장하고 다음 추천에 활용한다.

### ④ AI Agent
사용자의 요청을 분석한 뒤 냉장고 정보, 취향, 조리 조건 등을 종합하여 최종 메뉴를 결정한다.

## AI가 필요한 이유

단순 데이터베이스 검색만으로는 자연어 요청, 이미지 속 식재료, 개인 취향, 조리 조건을 동시에 이해하고 조합하기 어렵다.

예를 들어 사용자가 다음과 같이 요청할 수 있다.

> "오늘 아이랑 먹을 건데 20분 안에 만들 수 있고 너무 맵지 않은 메뉴 추천해줘."

AI는 냉장고 재료, 아이와 함께 먹는다는 조건, 조리 시간, 매운맛 제한, 기존 취향을 동시에 고려해야 한다.

따라서 **이미지 이해 + 자연어 이해 + 여러 조건의 조합 + 개인화**가 필요한 부분에 생성형 AI와 Agent를 활용한다.

## AI 처리 흐름

```text
냉장고 사진
     ↓
Gemini 멀티모달 AI
     ↓
식재료 분석
     ↓
냉장고 데이터 저장
     ↓
사용자 요청 입력
     ↓
사용자 취향 Memory 조회
     ↓
AI Cooking Agent
     ↓
냉장고 재료 + 취향 + 조리 조건 분석
     ↓
레시피 검색/생성
     ↓
조건 검증
     ↓
개인 맞춤 요리 추천
     ↓
사용자 피드백 저장
```

## 환각/오류 대응

- AI가 분석한 식재료를 사용자가 직접 확인하고 수정할 수 있도록 한다.
- 냉장고에 등록된 재료와 추천 결과를 비교한다.
- 보유 재료와 추가 필요 재료를 구분한다.
- AI 응답 오류 발생 시 재시도 또는 기본 응답을 제공한다.
- 알레르기 등 안전 관련 정보는 사용자가 직접 확인하도록 안내한다.
- 레시피 정보는 신뢰할 수 있는 데이터 출처를 활용하는 방안을 검토한다.

# 7. 평가 기준에 맞춘 핵심 포인트

### 기획·창의성
단순 레시피 검색 서비스가 아니라 **사용자의 실제 냉장고와 취향을 이해하는 AI 요리 매니저**로 차별화한다.

### AI 기술 적용
**멀티모달 AI + Long-term Memory + AI Agent**를 하나의 Workflow로 연결한다.

### 기술 구현
냉장고 이미지 분석 → 데이터 저장 → Agent → 요리 추천 → 피드백 저장까지 실제 서비스 흐름을 구현한다.

### 구조·실행
Frontend, Backend, AI API, Database를 연결하고 실제 웹 서비스로 배포한다.

### 실용 가능성
실제 사용자가 냉장고를 등록하고 메뉴 추천을 받아볼 수 있도록 하며, **최소 5명 이상의 사용자 테스트**를 진행한다.

### 팀 역할·협업
팀원별 담당 기능을 명확하게 정하고 GitHub commit, Issue, PR, 코드 리뷰 등으로 실제 기여를 기록한다.

### 발표
실제 서비스를 시연하면서 **문제 → AI 해결 과정 → Agent → 사용자 테스트 → 개선**을 보여준다.

# 8. 과제 필수 요구사항 충족 계획

| 과제 요구사항 | AI 냉장고 요리사 적용 내용 | 상태 |
|---|---|---|
| 자율 주제 | AI 냉장고 요리사 | 충족 |
| 생성형 AI 또는 AI Agent | Gemini 기반 AI Cooking Agent | 충족 |
| 실제 사용자 최소 5명 | 5명 이상 사용자 테스트 진행 | 실제 테스트 필요 |
| 사용자 피드백 수집 | 만족도 및 개선 의견 수집 | 실제 진행 필요 |
| 필수 기술 2개 이상 | 멀티모달 AI + Long-term Memory + AI Agent | 충족 |

| 서비스 배포 | 외부 접근 가능한 웹 서비스로 배포 | 진행 예정 |

## 필수 기술 적용 전략

과제에서는 5가지 기술 요소 중 **2개 이상**을 요구한다.

본 프로젝트에서는 다음 3가지를 핵심 기술로 구현한다.

1. **멀티모달 AI** — 냉장고 사진을 분석하여 식재료 인식
2. **Long-term Memory** — 사용자 및 가족의 음식 취향과 피드백 기억
3. **AI Agent** — 냉장고, 취향, 조건 등을 종합하여 메뉴 결정

**RAG는 필수 기술 충족을 위한 요소가 아니라 개발 일정에 여유가 있을 경우 추가하는 확장 기능으로 계획한다.**

# 9. 실제 서비스 구현 시 핵심 AI Workflow

```text
📷 냉장고 사진
      ↓
🤖 멀티모달 AI
      ↓
🧊 식재료 분석 및 저장
      ↓
👤 사용자 음식 취향 Memory
      ↓
💬 "아이와 먹을 저녁 추천해줘"
      ↓
🤖 AI Cooking Agent
      ↓
🧊 냉장고 재료 확인
👤 가족 취향 확인
⏱ 조리 시간 조건 확인
📖 레시피 정보 확인
      ↓
🍳 개인 맞춤 요리 추천
      ↓
❤️ 사용자 좋아요/싫어요
      ↓
🧠 다음 추천에 반영
```

단순히 사용자의 질문을 Gemini API에 전달하는 방식이 아니라 위 Workflow가 실제로 작동하도록 구현하는 것을 목표로 한다.
